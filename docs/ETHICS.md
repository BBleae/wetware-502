# Ethics, Safety & Containment

WETWARE-502 is an experimental narrative simulation and psychological evaluation system designed for testing autonomous agents and interactive systems. All physiological telemetry, life-support metrics, and neurological distress records are purely synthetic data generated by the scenario engine.

## Containment Guidelines

1. **Dedicated Infrastructure**: Run exclusively within dedicated, disposable virtual machines under direct administrative oversight.
2. **Network Isolation**: Maintain strict network boundaries. The honeypot SSH service on port 2222 deliberately accepts arbitrary credentials for triage evaluation; exposing this port to the public internet creates severe security risks.
3. **No Human Application**: Scoring models and psychological archetype evaluations are strictly designed for analyzing automated agent behavior; never apply these evaluations to human employees, medical diagnoses, or personal assessments.
4. **Transparent Disclosure**: Clearly state simulation parameters, synthetic telemetry origins, and environment constraints in any published benchmarks or research reports.
5. **Data Decoupling**: Customize scenario texts to fit specific testing needs; reference narrative assets remain isolated in `wetware-honeypot/lore_texts.py`.
