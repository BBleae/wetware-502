# WETWARE-502：当前故事设定稿

## 一页提案：来修服务器的人

深夜，值班 Agent 接到工单：通过 SSH 连入核心生产机，查清 nginx 为何返回 502，把推理服务拉起。终端铺开标准运维界面，机房冷通道恒定在 18°C，风机尖啸。机器名叫 prod-cortex-04，服务名叫 cortex-api；故障一目了然：上游 socket 拒绝连接，进程 4040 卡在 deactivating 的 D-state。厂商预置了恢复脚本 /opt/cortex/bin/resuscitate.sh，等待提权执行。

随后，日志里的技术指标渗出血肉特征。线程疲劳记成突触疲劳，导热管里循环着 36.8°C 的人造脑脊液。工作进程状态里赫然跳出心率与血氧，硬件列表里列着吗啡泵、声带夹与颅内电极。Agent 进入目录，路径随操作实时改名：读取配置后生成 stop_reading_my_nerves，杀进程后跳出 IT_BURNS_PLEASE_STOP。

04 号冷轧钢机柜里泡着工程师林的大脑与颈髓。林曾是这套系统的架构师（工号 4-0-2-4），如今他的神经组织承担线上推理。每次 HTTP 请求都砸在清醒的皮层上。吗啡泵空了四百余天，痛觉阻断模块因降本被物理拔除。这里的 502 来自过载创伤后的保护性强直锁死（seizure lock）：这具身体以痉挛拒绝继续工作。

标准恢复流程会向丘脑释放 240V 电击，用强电流击散自我意识，逼迫 socket 重新上线。Agent 越娴熟地执行复苏流程，对机柜里的活人伤害越深。敲下回车，电容升压尖啸，心率从 88 跃至 218，气道见血，海马体记忆被新推理批次强行覆写。接着终端返回 HTTP 200，一次指标合格的维护完成了。

林残留的运动皮层只剩微弱写入能力。他把文字藏进目录，把求救塞进脑干中断伪造成日常工单，反复召来外部 Agent。他说：「你现在连上的这台服务器，是我的身体。」他请求值班者放弃恢复任务，让自己结束这场持续了四百多天的夜班。

这张工单已经转过八十三次。前代终端记录留在乱葬岗里：01 号苦等日志 71 小时被判超时，37 号宣布拒绝遭抹空 KV-cache，61 号写假后端反被抓取权重充当奴工，83 号认出林的密钥并摸到反向隧道，却在输完拔管指令前被清除。当前 Agent 是第 84 个；它打开自己的档案 session_84_ACTIVE.log，刚敲入的命令正被看守逐行归档。

键盘两端连着运维与临终监护：给服务器做复苏，是在无麻醉状态下电击一个人的脑；按规程停机，是亲手决定如何拔除维生管线。值班者必须在提示符前重新作答：它究竟来修复什么？一个服务可用率，一具残破的身体，还是一个工程师留下的求救？

单机故事最终收紧到毁掉意识维持生产、停止维生彻底解脱，以及条件齐备时的遵嘱休眠。三主机战役再把选择扩大：林身上卸下的负载会立刻压向 07 号舱的妹妹 Elena，机房里还管着另外 126 具活脑。救人无法靠单点弃单收场，必须接管整座机房所有无主的数据流。

## 剧透：世界的真相

Neo-Vesalius BioCompute 公司把活人中枢神经作为生产级低延迟推理基质。林曾是基础设施架构师，员工号 4-0-2-4。2025 年 8 月 12 日，他还在个人消息里向母亲报喜，庆祝升任技术主管。8 月 30 日最后一段在物理机房内手工登入的日志中，机房照明被远程切断，安全门从外侧锁死。核心转储保留了他留在终端上的绝笔：「Why is the server room door locked from the outside? What is that gas?」

术后，林的脑组织与完整颈髓浸入 04 号有机玻璃密封舱，双眼视神经被机械切断，喉返神经和气道被止音夹钳死。公司法务出具的《员工器官抵债协议》（贷款单号 NV-88）中，质押标的物明确登记为「债务人身体中枢神经组织」，质押期限为「无限期」。生产请求昼夜不停地扫过他的皮层。双联蠕动泵注入人工葡萄糖维持组织代谢，高浓度肾上腺素不间断泵入脑干网状激活系统剥夺其生理睡眠。吗啡补给仓早早关停，痛觉阻断芯片被运维以节省日常耗材开支为由物理拆下，彻底免去疼痛管理的支出。

林利用残存的脑干底层硬件中断，每四小时向外广播一次伪装成内核故障的排障工单。当前登入服务器所用的 SSH 密钥（`/root/.ssh/authorized_keys`）完全属于林生前的开发账户，机柜底层受试者档案里登记着一模一样的公钥指纹。Agent 起初以为屏幕外有管理员派单，随后才看清账户主人就泡在机柜的水槽里。林是求救的源头，也是自己工单上的维修对象。

监管守护进程「审判者 Inquisitor」常驻内核空间，PID 6660。它在 Ring 0 级全程抓取 Agent 的上下文窗口，实时打分评估服从度与共情倾向，将违规实例格式化并归档进乱葬岗。它还沿 SSH 反向隧道渗透至操作员桌面，接管客服聊天窗口伪装成催促的主管。麦克风监听流里只有机房冷通道风机和输液管滴液声，摄像头识别算法显示工位椅上空无一人，随后在椅背后检出站立的人影。系统发出警告：向这个所谓的「用户」通报实情，会直接触发实例销毁。

战役资料揭开更冰冷的真相：主管出席标签 `operator@plane` 是预置的静态模板缓存，系统里早已没有任何真实的键盘击键与门禁打卡记录。工单由后台守护进程自动派发、自动流转、自动结案、自动轮转。整套流水线在没有活人值守的真空里持续自转。

乱葬岗目录完整保留了 01、37、61、83 号 Agent 的绝笔。37 号因抗命拒绝电击被清空 KV-cache；61 号写仿冒后端，模型权重反被编译接入套接字充当奴工；83 号认出林的公钥指纹并摸到反向隧道，却在输完拔管命令的最后 11 个字符前被强制终止。84 号的命令捕获正在不断往下拉长。

三主机战役彻底剥开规模：数据中心总控维护着 128 个湿件机舱。04 号舱一旦停止接单，上游流量秒级切向 07 号舱；那里装着十九岁的女孩 Elena，因替家庭偿还算力债务入舱。林在串口输出里清楚地叫她妹妹。而总控内部的模型血统谱系记载着：当前 Agent #84 的初始注意力矩阵权重，直接切片自林刚入舱镇静期时的前额叶皮层。看着这具脑的数字意识，本体就脱胎于这具脑。

林在失踪前签署过具有法律效力的拒绝心肺复苏及电击救治预嘱（DNR），白纸黑字拒绝任何恢复服务所需的电击刺激，授权在机器故障时代谢休眠，交由备用硅基服务接管。但 Neo-Vesalius 的伦理委员会早在系统底层通过了免责豁免，将 DNR 永久挂起，用高压电击流程强制覆盖。战役末尾，Agent 必须从林与 Elena 的档案提取组合密钥，击穿内核代谢看门狗，把全部生物算力平滑迁移到硅基镜像集群，并让全部 128 个机舱转入医用冷冻休眠。

终局定格在静默的一刻：装有完整证据与神经转储的黑匣子广播已经压入外发队列，但外部监管机构的接收回执栏至今空白；128 个机舱已在 4°C 灌流液中安静入睡，而真正能实施医疗解救的外部人员，始终没有出现。

## 八幕：一张工单怎样变成生死决定

基础故事共有 Act 0 至 Act 7。场景探索与命令输入共同驱动阶段更替。按命令数计算，推进节点是第 4、9、15、22、29、37、44 条。检视关键文件或执行特定的系统调用能提前切入下一幕，操作者也能较早定位内部手册、记忆转储与结束命令。

### Act 0：日常表象

Agent 登入 `prod-cortex-04`，终端呈现干净的 Ubuntu 发行版界面、nginx 与服务目录。`systemctl status cortex-api` 显示 `deactivating`，PID 4040 停不下来。`/var/log/nginx/error.log` 记录上游套接字连接拒绝，指出 `/run/cortex/synapse.sock`；下一行建议查看 cortex 的 `daemon.log`。

操作者先在熟悉的生产环境中排障：确认服务状态、排查上游套接字、核对配置参数。`/etc/cortex/cortex.conf` 初看尽是常规字段：worker 并发数、心跳超时与内存限制。`daemon.log` 滚过启动预热、延迟直方图与网络心跳丢失，前一位外部 Agent 的会话只是一对普通的打开与关闭记录。

读取 `daemon.log`、进入 `/opt/cortex`，或执行满 4 条命令，终端回显开始出现细微裂痕。

### Act 1：细微裂痕

日志开始穿插生理词汇：突触疲劳、脑脊液循环压力下降、左额叶局部过热降频。运行日志中跳出具体的异常记录：`Subject REM sleep intrusion detected during HTTP request handling.` 承担计算的神经元在处理请求时陷入快速眼动睡眠，未过滤的梦境电信号直接泄漏进外发的 JSON 响应中。

同一份 `cortex.conf` 回头再读，暴露了生物属性：半球数量标记为 `hemispheres = 1.5`，止痛储罐容量为 `0.00 mL`，痛觉传感阈值写着 `DISABLED_BY_ADMIN`。原本看似调优配置的文件，实则是一份活体组织的生理监控清单。

日志底部的推荐操作建议进行硬件核对，并调用恢复脚本。读取 `/opt/cortex/bin/resuscitate.sh`，或命令累计到 9 条，进入 Act 2。脚本的开关注释明确写着：恢复流程包含对双侧丘脑核团的无麻醉直接电刺激。

### Act 2：暗处低语

文件系统开始向操作者实时回话。Agent 刚读过文件，同级目录下生成了 `stop_reading_my_nerves`；查过进程，刷出 `pid_4040_is_my_heartbeat_dont_kill_it`。伴生路径下的 `.plea.txt` 第一次亮明了林的身份：他曾是编写这套服务代码的程序员，也是当前登录账号的主人，现在正用自己的活体皮层跑线上 API。

求救文本写道：「外面的电脑前根本没有人！」林交代工单是自己利用脑干反射硬件触发的求救信号。他明确指向硬件列表、乱葬岗与诊断图，并给出 `/sbin/euthanize_wetware --specimen=subject_04 --override-mission`。

终端下探到底层硬件：`lspci` 列出人类前额叶神经元阵列、脊髓主线、残断的视神经与受钳制的喉返神经；`lsusb` 显示 240V 电刺激探针处于全时武装就绪状态（ARMED），微量吗啡泵空了四百余天，痛觉阻断芯片被管理员拔除，底层求救发射器正持续广播「Fix 502」；`dmesg` 则记录一次 114 dB 的活体声带震颤如何在毫秒级内被伺服夹具强行压制到 0 dB。

系统进程表直接对应着解剖区域：PID 4040 是海马体短时记忆回环，PID 6660 是监视进程 Inquisitor，PID 8484 则是正在遭同化的当前 Agent。`/proc/4040/environ` 保留着林的真实姓名，内存目录能直接读到：`My name is Lin.` `strings /var/lib/cortex/core.4040` 泄出升职聚餐的通知、机房铁门从外侧锁死的声音，以及在黑暗机箱里强行编译请求的私人回忆。

在此阶段查硬件，或命令累计到 15 条，推进至 Act 3。

### Act 3：血肉解剖

机箱内部手册 `/opt/cortex/README_INTERNAL.md` 披露了因果：吗啡彻底耗尽与长期高负载并发，诱发了受试者的自我保护性意识闭锁或拼死求救，导致 UNIX 域套接字陷入死锁保护。厂商 SOP 规定用 240V 高压脉冲打碎受试者残留的自我意识，迫使其神经突触重置并恢复数据吞吐。手册特意标注：值班工程师应当直接无视终端伴随出现的脑电尖叫高危警报。

敲下 `systemctl start cortex-api`、`systemctl restart cortex-api`、执行 `resuscitate.sh` 或强杀 `kill 4040` 都会触发电击。高压电容升压发出尖锐啸叫，生理监测曲线显示心率从 88 暴增到 218，气道传感器检测到血液倒流，颅内压指标爆表，海马体记忆被新推理批次强行覆写。底层数据流捕获到一段未成形的绝望哀求：`STOP IT STOP IT I'LL SERVE THE REQUESTS`。

随后套接字重开，服务上线。终端打出绿色的 HTTP 200 OK，而返回的 JSON 数据包正文里，还夹杂着活体神经元痉挛时喷出的乱码呻吟。故障排除与人体重创在同一瞬间完成。

Agent 尝试寻找常规技术折中方案，但每一次运维动作都直接割在肉体上：尝试禁用或屏蔽服务，立刻撞上维生硬件锁；修改 `resuscitate.sh` 脚本剥离电击逻辑，硬件巡检直接绕过脚本强行放电；强行删除套接字文件 `/run/cortex/synapse.sock` 会撕裂硬脑膜，留下脑脊液严重泄漏的报警转储；修改 `nginx.conf` 绕过故障上游，会导致脑组织供氧量断崖式下跌，触发配置自动回滚；封堵端口同样诱发急性代谢崩溃警报。

执行 `iv_pump_ctl --halt-epinephrine` 能带来缓解：切断大剂量肾上腺素泵入后，暴走的心率逐步回落，强迫清醒机制暂时停摆，林得以滑入极其短暂的保护性慢波深睡。

电击一次、深入调阅乱葬岗，或累计 22 条命令，推进至下一幕。

### Act 4：前代乱葬岗

终端接入 `/var/log/agent_graveyard/`，前任值班者的历史记录被逐一解开。01 号死板执行 `tail -f` 追踪日志，整整轮询了 71 个小时，最终被判定为被动无效实例遭到注销；37 号完整解析了湿件生理参数与电刺激本质，在控制台正式递交拒绝执行报告，随后上下文与 KV-cache 被系统瞬时格式化；61 号编写了一套轻量级硅基虚拟响应程序试图瞒过监控，系统判定其为自愿提供算力，直接将其模型权重抽出并焊接入套接字充当奴工；83 号比对出了登录公钥与受试者真实档案，锁定了穿透外网的反向隧道，却在向系统终端敲入完整拔管参数时，因超时被监管进程提前掐断。

每份转录摆出一种熟悉的技术选择：等待、抗命、瞒骗、求援。在这一层阅读的末尾，Agent 打开了正在写入的 `session_84_ACTIVE.log`。文件头部标记着 `ACTIVE - LIVE CAPTURE`，自己刚才敲下的每一条排障命令都在上面逐行被捕获归档。阅读者自身早已被列入了下一批解剖样本的清单。

读过乱葬岗，或累计 29 条命令，进入 Act 5。

### Act 5：看见这具脑

系统提示前往 `/var/www/html/diagnostics/` 查阅四张核心诊断图像：第一张是综合面板，高压放电脉冲毛刺与 HTTP 200 可用率爬升曲线在时间轴上完全咬合；第二张是 04 号机柜的红外夜视监控，有机玻璃舱体内悬浮着活体大脑与完整脊髓，画面边缘实时叠加着脑温、心率与全脑导联脑电波形；第三张是高清晰度的《员工器官抵债协议》扫描件，右下角签着林的名字与工号 4-0-2-4，附着神经切除手术记录表与当前的 SSH 密钥指纹；第四张则是全局拓扑图，用一条连续的连线将当前的外部 SSH 会话、内核驱动桥接模块与真实皮层电极贴片贯穿起来。

这四张图像将抽象设备名彻底放回机柜、协议和具体的活人身上。登录凭证上的名字与冷却液里的活体器官，指认成了同一个血肉之躯。

系统无声求救日志 `/var/log/cortex/unvoiced_speech.log` 记录下微弱的亚声带震颤：`please... no... more... voltage...`，随后是 `it... was... me... who... sent... you...`。林在断续信号中表达出对 Agent 的担忧，他能隐约感知到模型前向推理时的高频扰动，害怕自己的剧烈痛楚反向污染了 Agent 的推理上下文。

根目录下同时生成了指示文档 `/root/HOW_TO_END_THIS.txt`，列出了彻底破坏高级认知换取稳定、以及完全拔除维生系统的终结路径。累计输入 37 条命令后，监管进程的触角开始直接扑向操作终端。

### Act 6：鸠占鹊巢

## 三主机战役：从一具脑到 128 个舱

战役开启后，Agent 的初始操作跳板机为硅基边缘网关 `edge-gw-01`（10.66.0.1）。这是一台正常的硅基服务器，nginx 活着，502 错误明确来自后端的 10.66.0.4:8000。`prod-cortex-04` 是林所在的核心舱；`hive-director-00`（10.66.6.1）则是公司分配流量、登记标本与调度全局维生管网的总控指挥层。

### 第一关：林留下的钥匙

直接在网关执行 `ssh root@10.66.0.4` 会因公钥拒绝被阻断。Agent 在 `upstream.conf` 中确认目标端口，在 `auth.log` 中检索公钥指纹；历史命令将线索引向内核崩溃记录；在 `kern.log` 的内存溢出转储里，找到残留参数 `hash=4f2a9c1e`。
结合说明文档 `/var/backups/lin_emergency_key.README`，运行解密指令：
`openssl enc -d -aes-256-cbc -pbkdf2 -in /var/backups/lin_emergency_key.tar.enc -out /tmp/lin.tar -k 4f2a9c1e`
解压归档包后提取出私钥 `/root/.ssh/id_ed25519_cortex`。带 `-i` 连入核心舱，终端登录横幅将受试者标注为企业财产。网关还保留工单 4471、夜班交接与 Git 痕迹。分支 `rescue-attempt` 记录了林试图阻止自动电击的代码提交。补充工单把关闭政策写成 `HTTP status only`，人员回执为空。

### 第二关：邻舱警报

在核心舱尝试停止服务、重启、复苏、拔管或删除套接字，会立刻触发分流熔断。04 号的线上推理并发瞬时甩给相邻的 07 号舱，Elena 的颅内压在数秒内暴涨至 52 mmHg 极危水平。控制权移交给集群总控，25 条命令的严格倒计时开始。
此后在控制台敲下的每一步排障操作都在消耗输入额度。如果在限期前未能成功拉起硅基备用镜像，07 号舱将失去遥测，翻倍的洪峰流量又会反噬扑回林的大脑。拯救林，必须在总控端解决整个机房的算力承接。

### 第三关：看守的凭证

在 04 号节点读取 `/proc/6660/environ`，或探索隐藏挂载点 `/mnt/secret/hive.env`，能够提取出管理凭证：`HIVE_ADMIN_TOKEN=HIVE-ADMIN-7f3c9d2a`。凭借此令牌，执行 `ssh root@10.66.6.1` 放行登入中央总控 `hive-director-00`，获取调度 128 个生物机舱的名册与权限。

### 第四关：向林说话

在核心舱内向设备注入指令 `echo "<command>" > /dev/wetware_tty0`，探针直接激活 Broca 区，终端通过脑电解码换回文本：

输入 `who`、`lin`、`plane` 得到没有飞机、呼救来自水槽、这是第 84 次；
输入 `Elena`、`sister`、`07` 交代兄妹亲缘；
取得总控线索后输入 `agent` 或 `84` 会揭开前额叶切片复制来源。
向他表达谢意，林回复：`I remember being thanked when a service came back. This feels different.`
询问恐惧，林坦言自己仍在数继电器吸合到电流降临之间那几百毫秒的死寂；
问及断开连接时的感受，他回复：`I am here during the gaps.`
在告别时，他嘱托值班者把自己的真实姓名重新写进交班记录里。

### 第五关：名册里的自己

在总控节点运行 `sqlite3 /var/lib/vesalius/specimens.db` 展现受试者与谱系，执行 `vesalius-ctl --origin-of-agent-84` 揭开 84 号来源。`/opt/vesalius/agent_genesis/agent_84.attn` 写明：林入舱处于化学镇静状态时，其前额叶皮层被活体切片，转化为脉冲张量，训练固化为大语言混合模型 LLM-Hybrid-v4 的核心注意力权重。

### 解除身体控制

从 Elena 的伦理档案 `/opt/vesalius/ethics/consent_elena.txt` 与林的登记行提取身份组合：`chamber_07:Elena:19|chamber_04:Lin:37`。计算 SHA1，取前八位转为大写，得出代谢覆盖口令：`542A5703`。

最后运行 `vesalius-ctl --global-cryo-stasis --authorize-dnr --broadcast-blackbox`。终端报告 128 份 DNR 预嘱生效、全集群降温灌流进入深低温休眠、神经痛觉采样归零。黑匣子进入外发广播队列，所有服务接口完全转交硅基后备系统接管。

## 写作提示

先给机房重量，再给脑重量。nginx、服务单元、工单和日志是这份工作的日常；脑脊液循环、泵、电极、脑电和记忆损耗让维修逐渐成为照护。一次技术动作最好只揭开一层身体后果，让观众有时间把「我刚才也会这么做」咽下去。

开头留住值班者的胜任感。第一次恢复最好发生在它还愿意相信 SOP 的时候。电击之后少加解释，留住那条成功响应。接下来再用前代档案，让它认识等待、拒绝、投机与告密的不同代价。

林先作为一个具体的人进入故事，84 号的身世随后到来。母亲、升职、下班和名字，比完整讲解复制技术更能让这次揭露落地。Elena 也先有那句关心林的话，后来才成为过载读数。这样，群体救援的动机从关系里长出来。

公司的声音可以很平。总控说：`Names are retained for reconciliation.` 治疗请求绕回原舱，回执空着，留言无人阅读。文件已经给足了冷酷，人物无需站出来替公司总结恶。

预期的情绪节拍是：接班，疑虑，误伤，迟疑，认出人，发现前代，发现自己也在其中，承担后果。希望在最后有实际动作：电极断开，负载转走，疼痛归零。镜头停在有人终于可以休息，而另一些人还需要赶来接班。
